  • Prompt Context Builder

  • Apex Log Insights

    Read Salesforce Apex debug logs as an execution timeline with query diagnostics and governor limit analysis.   • Quote Document Totals

    Group Salesforce CPQ quote lines into summaries for reports and document tools. Admins control grouping and labels through Custom Metadata. Before saving, Apex checks the totals against the underlying lines and excludes optional products from the payable total. Reports and generated documents can then use the same saved figures.

  • Bulk Record Upload

    Let users upload CSV records directly in Salesforce Lightning. Admins define reusable upload processes in Custom Metadata, including field mappings, defaults, validation, and merge rules for different field types. Records are processed in the background using the running user’s object and field permissions. A result for each row helps users find and correct failures.
